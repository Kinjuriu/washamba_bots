## Shape

A single-file agent, `agents/washamba_splice_v1.py`, generated by `experiments/splice/build.py`:

```
<base agent, byte-verbatim>         # W3 by default; experiments/splice/base_choice.md may change it
_WB_BASE = [v for v in list(globals().values()) if callable(v)][-1]   # the base's REAL entrypoint (see note)
<experiments/splice/price_model.py> # all names prefixed WB_ / _wb_
<experiments/splice/sell_engine.py>
<experiments/splice/controller.py>
def washamba_agent(obs, config=None):
    if obs step < WB_HANDOVER_STEP: return base action   # base plays days 0-7 untouched
    return WB_CONTROLLER.act(obs)                          # controller emits EVERYTHING from step 192
agent = washamba_agent                                     # must stay the last callable binding
```

- `WB_HANDOVER_STEP = 192` means day 8 at hour 0. At that point the hands have vanished, the farmer is at spawn, and no internal tape state is needed (R2.3, handover checklist).
- **The base's entrypoint is its last callable, not `agent`.** In W3 the name `agent` is an older binding that skips about ten later wrapper layers (`final_price_guard` through `herdsafe_forecast`). Kaggle runs `herdsafe_forecast_agent`, the last callable in the module. Capture it with the list expression above, immediately after the base text and before any `WB_` code, because classes are callable too.
- When built, each module drops its package imports, including the bare-name ones (`from price_model import ...`, `from sell_engine import ...`). Every top-level name carries the prefix `WB_` or `_wb_`, so nothing collides with the base's globals.
- Any exception inside the controller is caught per turn. The fallback is a safe action: feed and water whatever is due, pass otherwise. The fallback must never be the base's tape, because after handover that tape is out of sync.

## Interfaces (frozen; change only by agreement recorded here)

```python
# price_model.py
class WB_PriceModel:
    def quote(self, item: str, inventory: float) -> float          # == engine market_price, exact
    def sell_revenue(self, item: str, inventory: float, qty: int) -> float   # unit-by-unit, pre-sell quotes
    def buy_cost(self, item: str, inventory: float, qty: int) -> float       # unit-by-unit, post-buy quotes
    def drain_per_step(self, item: str, unlocked_shops: list, step: int) -> float
    def project(self, item: str, inventory: float, unlocked_shops: list, step: int, horizon: int) -> list[float]

# sell_engine.py
class WB_SellEngine:
    def __init__(self, price_model: WB_PriceModel): ...
    def orders(self, obs: dict, sellable: dict[str, int], slots: int) -> list[list]:
        """At most `slots` SELL orders for THIS turn, most valuable first, slot-0 first.
        sellable: units the controller releases for sale this turn. The controller has already
        removed its own needs, such as feed wheat and fertilizer it will apply."""

# controller.py
class WB_Controller:
    def __init__(self, price_model, sell_engine): ...
    def act(self, obs: dict) -> dict        # {"farmer": [...], "hands": [[...], ...], "market": [[...], ...]}
```

**Market arbiter (controller, 10 orders per turn).** Priorities, highest first:
1. Critical buys: an animal purchase scheduled today, and feed wheat when the shed can't cover tomorrow.
2. The sell engine's slices on cadence turns.
3. Morning hires. Twelve hires take two turns, and they must not crowd out a cadence slice.
4. Seeds, sized to the plantings the executor will actually make. Planting more seed of a crop than you hold voids all of that crop's plantings that turn.
5. Land.

## Engine facts to verify, not trust

- **Cadence.** Shops consume at steps where s % 4 == 0, after that call's market processing. Stephane measured the earliest post-drain sell at row ≡ 2 (mod 4). Confirm this against the engine on a probe episode, using the convention that `steps[i]["action"]` was decided from `steps[i-1]`'s observation. That same off-by-one convention misled the Sept 13 diagnosis.
- **Market timing.** The market resolves after unit actions in the same call. Seeds bought this turn plant next turn, and a hand hired at hour h first acts at h+1.
- **Structures.** A goose needs a COOP and a cow or sheep needs a PASTURE. A mismatched PLACE drops the animal into the shed (see `docs/ENDGAME/v3_results.md`).
- **Watering.** A planting not watered the same day turns to weed overnight.
